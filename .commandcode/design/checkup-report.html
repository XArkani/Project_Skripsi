// PRIORITY ISSUES
P0

No reduced-motion support

All 7 Framer Motion animations (Hero, QuickNav, Blueprint, Dosen, Event, News, FAQ) ignore prefers-reduced-motion. Users with vestibular disorders get forced motion with no opt-out.

FIX: Add useReducedMotion() hook from Framer Motion, wrap all initial/whileInView animations with a check. Or use CSS @media (prefers-reduced-motion: reduce) globally.
P0

Text too small for mobile readability

text-[10px] (Dosen expertise labels, Blueprint category badges), text-[11px] (Dosen position), and text-xs (12px) in multiple places. Minimum readable body size is 16px on mobile.

FIX: Raise minimum text to text-sm (14px) for captions, text-base (16px) for body on mobile. Use text-xs only for truly auxiliary labels.
P1

Generic hero background image

Hero uses a generic Unsplash circuit/tech abstract (photo-1451187580459) that says nothing about Fakultas Teknik Universitas Hamzanwadi. Could belong to any tech company's landing page.

FIX: Replace with faculty-specific image — campus photo, engineering lab, student activity, or geometric emerald pattern using the FT logo.
P1

Identical section templates

All 5 preview sections (Blueprint, Dosen, Event, News, FAQ) use: wrapper → flex justify-between header → grid of cards → "see all" link. After the third section the rhythm becomes mechanical.

FIX: Vary layouts — Dosen as horizontal carousel, News as 2+1 asymmetric grid, FAQ as accordion, keep Blueprint cards since facility cards are genuinely card-shaped.
P2

No image optimization

All <img> tags use raw HTML without width/height, loading="lazy", or Next.js Image component. Causes Cumulative Layout Shift (CLS) and unnecessary bandwidth on mobile.

FIX: Replace all <img> with Next.js Image, add sizes attribute, use loading="lazy" for below-fold images.
P2

Hero height pushes content below fold

Hero uses min-h-[75vh] — on a 667px iPhone SE, ~500px of hero before any content. Information-seeking visitors must scroll past a large decorative block.

FIX: Reduce to min-h-[60vh] or min-h-[50vh] on mobile. Leave 40-60px of QuickNav visible to signal scrollability.
